# EEG_Signal_Processing

A step-by-step EEG simulation explanation for absolute beginners.

In this project, we build a simple EEG simulation step by step:
- We first model the clean activity starting with a single sine wave (Module 1),
- And then combine frequencies into a complex wave (Module 2),
- Before adding source mixing (Module 3) and noise.

For all the modules, the phase shift is considered to be zero, which is different from real data. Here we are just trying to make it as simple as possible.
